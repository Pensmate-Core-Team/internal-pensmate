# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Laravel 12, Blade, Tailwind CSS 4, Vite.

## Users

Admin dan member tim konten Pensmate.

## Product Purpose

Menyiapkan draf konten, menyimpan referensi per konten, dan mengelola anggota tim.

## Operating Context

Member membuat draf dan mengajukan review. Admin menyetujui atau meminta revisi. Posting dilakukan manual, kemudian link publikasi dicatat.

## Capabilities and Constraints

Lingkup: fitur 4 (draf siap upload), 5 (referensi di timeline), dan 6 (manage member). Timeline bulanan lokal kini mengintegrasikan link referensi sesuai permintaan pengguna. Feed tersedia untuk kalender rekan tim; poin, absensi dan plotting job tetap di luar modul ini. Satu model Content menjadi titik integrasi timeline. Akun nonaktif mempertahankan histori. Admin dan member memakai otorisasi backend.

## Brand Commitments

Nama produk Pensmate. Antarmuka berbahasa Indonesia. Desain menggunakan taste-skill dan impeccable.

## Evidence on Hand

Proyek awal masih kerangka Laravel. Belum ada identitas visual, autentikasi, atau modul konten.

## Open Decisions

Deployment dan akun admin produksi belum ditentukan. Data demonstrasi hanya untuk pengembangan lokal.
